How this works. When you answer a quiz inside an SOP video, the result is written to your browser's localStorage under sop-<ID>:quiz-results. This page reads those keys and displays them — nothing is sent to a server.

Per browser, per user. Progress is local to this browser profile. Two staff members using the same workstation under one profile will share progress. Two browsers or two devices keep separate progress.

Reset. "Reset all progress" clears both quiz results and the "watched" flags for every SOP. It does not affect any saved file or external system.
