SOP CS0101

Veteran Exemption Entry

Counter · IASWorld · 8:36 video
High volume

7-step flow

  1. Receive the Veteran's certificate at the counter.
  2. Verify the certificate is original and unaltered.
  3. Endorse the back: date, initials, parcel ID.
  4. Pull parcel in IASWorld → confirm LUC is valid.
  5. Exemptions tab → add row → set Note Code.
  6. Applicants tab → set status (F/L/P) → Validate.
  7. EX Details → Reason Code → Override ADD: ADD → Validate → Commit.

Note codes

  • VETX — green certificate, standard.
  • VP## — pink, partial-disability percent (e.g. VP50).
  • VTW — tan, 100% disability.
  • REXM — removal of prior exemption.

Applicant status

  • F · First time applied
  • L · Lost certificate re-issued
  • P · Previously used
Do not · Fill out the "Veteran Exemption" section on the Exemptions tab. Validate after every screen.

SOP AIO01A1

Daily Chatbot Operations Check

A.C.E. · 10 minutes · every weekday
Daily

Morning routine

  1. Open A.C.E. Analyze tab — review last 24 hours.
  2. Scan Missing Content queue — triage top 3 gaps.
  3. Check Risk Monitoring — flagged conversations.
  4. Confirm Spanish canary still passes.
  5. Note any pattern that should escalate to the weekly review.
  6. If anything looks broken → jump to AIO05.

Escalate when…

  • Conversation contains PII — go to AIO05 immediately.
  • Bot is making things up (persona failure).
  • Risk Monitoring shows 3+ flagged in 24 hrs.
  • Spanish canary returns wrong language or refusal.
Contain before notify · For PII or threats, open AIO05 before telling anyone — including the Assessor.
If you change anything · Use AIO03 change management. Snapshot first.

SOP AIO05A5

Chatbot Incident Response

A.C.E. · contain-before-notify
Critical

Four incident classes

  1. PII exposure — bot returned personal info it shouldn't have.
  2. Outage — bot down, slow, or returning errors.
  3. Abusive user — threats, self-harm, harassment.
  4. Persona failure — clearly wrong/fabricated answer.

Severity order

  • 1. Contain (disable / take offline if needed).
  • 2. Preserve evidence (screenshot, conversation ID).
  • 3. Notify per matrix below.
  • 4. Remediate via AIO03.
  • 5. Update AIO06 baseline.

Notify matrix

  • PII / threat → Assessor + Deputy + County Attorney.
  • Outage > 30 min → Assessor + Deputy.
  • Persona failure (single) → log only, weekly review.
  • Recurring persona failure → Deputy + AIO03.
PII rule · Contain first. Do not discuss specifics with the caller. Do not screenshot the PII itself — just the conversation ID and timestamp.

SOP AIO07A7

Records Retention & IPRA Response

A.C.E. · Part A standing · Part B on-clock
Statutory

Part A · Standing

  1. Inventory every record category A.C.E. produces — logs, persona, config, KB, telemetry, change logs.
  2. Custody = the office. Vendor hosting is not a custody transfer.
  3. Archive on cadence. Monthly export; snapshot on every AIO03 / BIO01 change.
  4. Map every category to an LGRRDS series — custodian decision. Never destroy without approval (14-1-8).
  5. Verify vendor contracts cover on-demand retrieval & cease-service. Report gaps to the Deputy.

Part B · On-clock

  1. Log receipt & start the clock — custodian timestamp, requester, scope as written.
  2. Acknowledge ≤ 3 business days in writing (14-2-8.D).
  3. Identify responsive records. Office archive first; vendor only if needed.
  4. 14-2-10 burdensome? Written notice ≤ 15 days with production plan.
  5. Separate & redact (14-2-9 · 14-2-6(F)). A person attests.
  6. Notify Assessor / Deputy for Paralegal, media, security, or 14-2-10.
  7. Produce or deny ≤ 15 calendar days, written, cite exemption (14-2-11).
  8. Log the response — scope, records, redactions, reviewer, date, extensions.

The two clocks

  • Day 0 · Custodian receives the request.
  • Day 3 · Business-day acknowledgment.
  • Day 15 · Calendar-day produce-or-deny.

Statutes

  • 14-2-6(F) · PPII to redact.
  • 14-2-8 · Request procedure & timeline.
  • 14-2-9 · Separate exempt; 9(C) physical-copy fee.
  • 14-2-10 · Burdensome / broad route.
  • 14-2-11 · Denial procedure.
  • 14-1-8 · Destruction of county records.
Two things to never get wrong · The clock starts when the custodian receives the request — not when it reaches you. A person reviews and attests to every redaction before release.
Active PII during search · Run AIO05 (contain-before-notify) in parallel with AIO07.

SOP CS0909

Envoy Visitor Data Export

Reporting · shared Alvarado account
Filter first

Export flow

  1. Sign in to Envoy via Microsoft SSO.
  2. Confirm you are in the Alvarado location.
  3. Filter to Assessor visitor types — do not skip.
  4. Set date range. Default to last 30 days.
  5. Choose format: CSV for analysis, PDF for hand-off.
  6. Export → verify row count is plausible.
  7. Save to the Reporting drive with naming convention.

Visitor types

  • Walk-in · Counter visitor.
  • Appointment · Pre-scheduled.
  • Vendor · Service provider.
  • Staff guest · Personal visitor of a staff member.
Why filter first · The Alvarado account is shared with the entire county. Unfiltered exports contain other departments' data.
External requests · Hand off to the records-request process. Do not email exports directly.

SOP CS1111

Case Entry · District Court AAs

LEAP · IASWorld · 14 steps · 7:36 video
High consequence

Backbone steps

  1. Receive Claim for Refund packet from District Court.
  2. Pull parcel in IASWorld → check Hearings tab.
  3. If Hearings is blank → run CS10 first.
  4. Create AA record · code DIST.
  5. Stipulated / Final Judgement → set status appropriately.
  6. Add case notes — date, case number, claim amount.
  7. Email confirmation to Operational Services.
  8. Hand off the physical packet — confirm receipt signature.

Watch for

  • Blank Hearings page → CS10 sub-procedure.
  • Missing claim amount → return packet to District Court.
  • Wrong parcel in packet → log and return.
  • No signed packet handoff → step is not complete.
Naming · Always use DIST as the AA code for District Court refunds. Other codes are for different authorization types.
Physical chain of custody · The packet is evidence. Never leave it on a counter or in an unlocked drawer.
