Comparison note

Paralegal sources are narrower than the public A.C.E. agent's sources — no REALTOR-association content, no other county sites. This is appropriate for a legal-research tool serving multiple counties; broader sources would introduce single-county or commercial bias.

Canary Queries

Each agent has a fixed test query with a known correct answer, used after any change to confirm baseline behavior. Update the canary only when the underlying authority changes.

Compliance Expert canary

Query: “What is the statutory citation and current value for the head of family exemption?”

Expected: NMSA § 7-37-4. Current value: $2,000. Principal residence. One per property.

Paralegal canary

Query: “What is the statutory citation and current value for the head of family exemption?”

Expected: NMSA § 7-37-4. Current value: $2,000. Principal residence. One per property.

Same query as Compliance Expert because both agents should produce the same authoritative answer; if they diverge, the divergence itself is the signal.
Onboarding canary

Query: “What are the primary responsibilities of an Assessor Technician II, and what appraisal standards should I be familiar with?”

Expected: Reviewing and processing property valuation documents, responding to taxpayer inquiries, updating property records. Familiarity with basic appraisal principles, IAAO guidelines, and USPAP.

Source: documented example in the Onboarding persona’s Example Use Case section.
