Purpose

Change management for internal CustomGPT agents: Compliance Expert, Paralegal, and Onboarding. Same Save → Publish discipline as the public agent (AIO03), with adjusted notification and review requirements because internal agents serve narrower, higher-stakes audiences.

For public-agent changes

Use AIO03. This SOP applies only to internal CustomGPT agents.

Which Agents This Covers

Compliance Expert

Internal legal research for office staff.

Paralegal

Statewide reference for NM county assessors (33 counties via Affiliate).

Onboarding

New-hire orientation at Bernalillo Assessor's Office.

Phone and Email agents are separate platforms not covered here.

How Changes Commit

Same model as the public agent:

Save
Per tab. Commits the edit within CustomGPT.
Publish
Top right. Pushes saved changes to users of that agent.
Actions toggles
Immediate — no Save, no Publish.
KB file uploads / deletes
Commit on the action itself.

Universal Rules

  • Confirm the right agent. Multiple agents share the platform UI. Verify the agent name in the breadcrumb at the top of the screen before editing.
  • Source the reason. For Compliance Expert and Paralegal, sources must trace to controlling authority (statute, AG opinion, court decision, PTD order, ordinance). For Onboarding, sources should reflect current office practice.
  • Screenshot before. Rollback reference.
  • Save then Publish. Most common failure mode is doing one without the other.
  • Test with the agent's canary query (see BIO04 Baseline). Plus one regression query.
  • Log the change. Single change log across all agents; tag the entry with the agent name.

APersona Change

Same procedure as AIO03 Section A (backup persona file, edit in Personalize → Persona, Save Changes, three test queries, Publish). The notification rules differ.

Compliance ExpertPersona Changes — County Attorney Review Required

The Compliance Expert persona encodes a hierarchy of legal authority, analytical method, and statutory citations. Edits can subtly shift legal analysis presented to staff.

  • Substantive persona edits (rules of analysis, hierarchy of authority, exemption order, valuation methodology, protest procedure, case law principles, edge cases) require written sign-off from the County Attorney before Publish.
  • Non-substantive edits (typo fixes, formatting, contact phone numbers, referral text) do not require legal review but must still be logged.
When in doubt

Treat the edit as substantive. The cost of an unnecessary review is small. The cost of a published legal-analysis change without review is large.

ParalegalPersona Changes

The Paralegal agent serves 33 NM county assessor offices via the Assessor Affiliate. Persona changes affect all 33 counties simultaneously.

  • Persona edits must be reviewed with the Assessor before Publish. Per January 2025 directive from Assessor Damian Lara.
  • Edits touching cross-county practice should be coordinated with the statewide affiliate before Publish.
  • After Publish, notify the affiliate distribution list so the 33 counties know what changed.

OnboardingPersona Changes

No external review required. Notify Deputy if the change affects how the office presents itself to new hires (mission language, tone, organizational structure).

BKB File Change

Same procedure as AIO03 Section B. Build → Sources → File Upload. Test after the Documents tab shows Added/Available = Ok.

Compliance ExpertKB Files

Source documents informing legal analysis (statutes, AG opinions, PTD orders, case digests) must come from authoritative sources only. Do not upload unofficial summaries, blog posts, or industry commentary. If a document is uncertain, route to County Attorney before upload.

ParalegalKB Files — Assessor Review Required

Per January 2025 directive from Assessor Damian Lara: KB additions to the Paralegal agent require Assessor review before upload. This applies to documents submitted by:

  • Bernalillo County Assessor's Office staff.
  • County assessor offices participating in the Assessor Affiliate (court cases, AG opinions, quick reference guides shared by other counties).
  • Any other source.
Standing directive

Maintain Assessor review as a hard prerequisite until rescinded in writing. The Paralegal KB is the only cross-county-shared KB in the program; uncontrolled additions affect every participating county.

OnboardingKB Files

Standard discipline applies. Source must be office-approved (HR documents, org chart, IAAO/USPAP references, policy documents). Log the change.

CActions Change

Same as AIO03 Section C — toggle is immediate, no Save, no Publish. Document Analyst conflicts with Webpage Awareness and Custom Button.

Web Search (Beta) on Compliance Expert & Paralegal

Strongly discouraged. Legal research grounded in unverified web content carries citation risk. If enabling is contemplated, notify Assessor and County Attorney.

DConfiguration Change

Same as AIO03 Section D. Save Settings (per tab) then Publish (top right). Configuration changes that affect the model, grounding, retention, visibility, or whitelisted domains require Assessor and IT notification before Publish, same as the public agent.

Compliance ExpertAdditional Rule — AI Model

Changing AI Model requires re-running the agent's canary query plus three diverse statutory questions before Publish. Model changes affect tone and analytical structure even when factual output is similar; for a legal research tool, that matters.

ParalegalAdditional Rule — Access

Configuration changes that affect access (whitelisted domains, visibility) must be coordinated with the Assessor Affiliate distribution list before Publish, because they may break access for participating counties.

Notify Before Publishing If

For all internal agents
  • The change affects how the agent represents office practice or policy.
  • The change responds to a complaint or correction request.
  • The change affects model selection, data source control, or security settings.
For Compliance Expert specifically
  • Any substantive persona edit — County Attorney written sign-off required.
  • Any KB document of uncertain authority — County Attorney review before upload.
  • Enabling Web Search (Beta) — Assessor and County Attorney notification required.
For Paralegal specifically
  • Any persona edit — Assessor review required (per January 2025 directive).
  • Any KB addition — Assessor review required (per January 2025 directive).
  • Configuration changes affecting access — coordinate with Assessor Affiliate before Publish.
